# 02 - Literatur

Direktori ini digunakan untuk menyimpan berkas ringkasan, sintesis, atau PDF dari literatur yang dikaji.

Pada riset eksperimental ini, literatur utama yang diacu berpusat pada:
1. Perbandingan kapabilitas indeks dan performa I/O PostgreSQL vs MongoDB.
2. Dampak algoritma *key-derivation* (seperti Bcrypt) pada *event-loop* Node.js.
3. *Performance bottleneck* antara lapisan *Database* vs lapisan *Application* pada Node.js saat beban *concurrent* memuncak.
