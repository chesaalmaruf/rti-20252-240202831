# 01 - Proposal

Direktori ini digunakan untuk menyimpan draf dan versi final dari proposal penelitian.

Dalam konteks praktikum RTI ini, bagian proposal mencakup pertanyaan penelitian yang mempertanyakan apakah jenis pangkalan data (Relasional vs Dokumen) memiliki dampak signifikan pada *endpoint* yang padat komputasi (CPU-bound) akibat fungsi *hashing* kriptografi (Bcrypt).
