# 5. Kesimpulan dan Saran

Penelitian ini menyimpulkan bahwa dalam desain aplikasi monolitik—di mana logika *hashing* kriptografis disatukan dalam antrean proses peladen pusat—PostgreSQL mampu mempertahankan kinerja I/O basis data dan *throughput* yang jauh lebih superior (14.67 RPS) dibandingkan MongoDB (0.31 RPS) pada skenario *high-concurrency*. Analisis tingkat-sistem membuktikan bahwa perdebatan mengenai indeks atau struktur memori basis data (Relasional versus *Document-based*) kehilangan relevansinya ketika ambang batas kerusakan sesungguhnya (*bottleneck*) berada di lapisan aplikasi; tepatnya, terblokirnya utas tunggal Node.js akibat monopoli beban CPU oleh algoritma keamanan sandi (Bcrypt). 

Berdasarkan temuan tersebut, sangat disarankan bagi pengembang aplikasi masa depan yang menghadapi target trafik autentikasi intensif untuk segera melakukan pemisahan (*decoupling*) fungsi kriptografi dari layanan pusat API (menerapkan arsitektur *microservices*). Beban *hashing* idealnya diisolasi (dialihkan) pada peladen agregat terpisah atau menggunakan fungsi asinkron dengan *worker pools* independen, agar tidak mencekik *event-loop* utama yang melayani panggilan pangkalan data.
